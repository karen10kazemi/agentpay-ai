## ⚡ Executive Summary

In the rapidly evolving **Agent Economy**, AI agents are transitioning from passive assistants to active economic participants. However, granting an AI unrestricted access to a cryptographic wallet introduces catastrophic financial risk. 

**AgentPay AI** solves this by introducing a **Programmable Trust Layer** on NEAR. Users and DAOs define strict, hardware-enforced financial guardrails (daily spending caps, slippage tolerances, and whitelisted chains) inside a **Trusted Execution Environment (TEE)**. Within these boundaries, the autonomous agent seamlessly executes recurring compute payouts, multi-chain contributor payroll, and optimal asset swaps using **NEAR Intents** and **Chain Signatures (MPC)**—with zero manual intervention.
